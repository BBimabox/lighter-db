# Lighter DB PWA v8

v8 重點：
- 保留 v7 的「我的最愛 / 已收藏」狀態，不增加複雜狀態。
- 每一筆已收藏型號自動取得唯一收藏編號：L0001、L0002…。
- 新增「收藏統計」頁：已收藏數、品牌數、最愛型號、價格紀錄、各幣別購入金額/平均、品牌/Tier/地區/購買來源/購買年份分布、最近加入收藏。
- 新增「打火機知識庫」：歷史、燃料與機構、日常保養、長期保存、收藏入門、年份與真偽辨識、購買前檢查、安全、30 秒檢查表。
- 知識庫支援關鍵字搜尋。
- 備份格式升級為 version 8，收藏編號包含在既有 models 資料中。
- Cloudflare Worker / OpenAI API 設定沿用 v6/v7，不需重新設定。

## 更新方式
把本資料夾全部檔案覆蓋上傳到 GitHub `lighter-db` repository 根目錄，Commit 後等待 GitHub Pages 重新部署即可。

若瀏覽器仍顯示舊版，電腦可按 Ctrl+F5；手機 PWA 可完全關閉後重新開啟，必要時先用瀏覽器開網站重新整理。
