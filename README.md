# Lighter DB PWA v3

291 筆品牌 / Maker 資料、離線搜尋、Tier 篩選、品牌收藏、品牌詳情、自訂型號、醒目的已收藏勾選、結構化收藏欄位、最多 5 張本機收藏照片、來源網址、參考資料庫、自訂連結、完整 JSON 備份/還原（含照片）。

## v3 新功能
- 已收藏改為大型勾選卡與明顯狀態標籤。
- 勾選已收藏後，獨立填寫購買年分、日期、價錢、幣別、來源、賣家、地點、品相、序號/刻字與備註。
- 購買來源使用下拉選單；選「其他」時可自訂。
- 每個已收藏型號最多可存 5 張照片，圖片存於裝置 IndexedDB，不會自動公開到 GitHub。
- 型號可再次編輯；之後買到原先未收藏的型號可直接補收藏資料。
- 完整備份可連照片一起匯出 / 匯入。
